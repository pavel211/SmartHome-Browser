# SmartHome-Browser
Браузер умного дома для Windows, открывающийся аналогично меню Пуск windows.

Простой браузер на основе Chromium, предназаначен для оперативного открытия панели управления умным домом. 

Окно находится в нижнем правом углу и запускается через автозагрузку. Если окно браузера не в фокусе, оно сворачивается в трей.

Открыть его через вызов ярлыка Show Browser Control. Для удобства рекомендуется закрепить его на панели задач и передевинуть в левый угол. Тогда запуск панели умного дома будет похож на запуск меню пуск.

Настройка
-------------------------

Настройка выполняется через меню "Settings", доступное через нажатие правой кнопки мыши на ярлыке программы в трее.

Можно настроить открываемую страницу и размер окна. По-умолчанию браузер открывает поисковик Google.

Компиляция
-------------------------

Компиляция выполяется через скрипт build.bat, создание установщика программы - через installer.iss (в программе Inno Setup).
